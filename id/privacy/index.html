Kebijakan Privasi

Terakhir diperbarui: 19 Mei 2026

Terima kasih telah menggunakan Vellum. Kebijakan Privasi ini menjelaskan bagaimana data Anda dikelola saat Anda menggunakan aplikasi Vellum ("Vellum").

Ringkasan Cepat

  • Vellum tidak memiliki server.
  • Semua kapsul Anda disimpan di akun Apple iCloud Anda, dienkripsi dari ujung ke ujung.
  • Kami tidak pernah memiliki akses ke rekaman audio, rekaman video, atau catatan pribadi Anda.
  • Saat Anda mengirim hadiah, kapsul dikirimkan langsung melalui iCloud ke penerima. Tidak ada perantara di antara kita.
  • Kami dapat mengumpulkan statistik penggunaan anonim; statistik ini tidak mengidentifikasi Anda secara pribadi.

1. Siapa Kami

Vellum dikembangkan oleh Vellum. Untuk kontak: vellumcapsuleapp@gmail.com

2. Data yang Kami Kumpulkan

2.1 Data yang Tidak Kami Kumpulkan

Vellum tidak mengumpulkan, melihat, atau menyimpan di server kami data berikut:

  • Rekaman audio Anda
  • Rekaman video Anda
  • Isi kapsul Anda
  • Catatan pribadi Anda
  • Informasi penerima (nomor telepon, nama)
  • Metadata dari kapsul yang Anda kirim atau terima

Semua ini disimpan di akun Apple iCloud Anda. Vellum hanyalah sebuah antarmuka — kami tidak memiliki server sendiri untuk mengakses data Anda.

2.2 Data yang Dikelola oleh Apple

Berikut ini dikelola melalui layanan Apple iCloud:

  • Penyimpanan data CloudKit
  • Pengiriman notifikasi push (Layanan Notifikasi Push Apple)
  • Sinkronisasi dan pencadangan iCloud

Privasi data ini diatur oleh kebijakan privasi Apple: https://www.apple.com/legal/privacy/

2.3 Data Penggunaan Anonim (Opsional)

Untuk meningkatkan Vellum, kami dapat mengumpulkan data anonim berikut:

  • Seberapa sering aplikasi dibuka
  • Fitur apa saja yang digunakan (misalnya, mengetuk "Buat Kapsul")
  • Laporan kerusakan dan statistik kesalahan
  • Versi aplikasi, model perangkat, versi iOS

Data ini tidak mengidentifikasi Anda secara pribadi. Konten kapsul Anda tidak pernah dimasukkan dalam statistik ini.

Jika Anda tidak ingin data ini dikumpulkan, Anda dapat menonaktifkannya di pengaturan iOS: - Pengaturan → Privasi & Keamanan → Analitik & Peningkatan → Bagikan dengan Pengembang Aplikasi (matikan)

3. Pihak Ketiga

Vellum menggunakan layanan pihak ketiga berikut:

Layanan Tujuan Data yang diakses
Apple iCloud / CloudKit Penyimpanan data Kapsul terenkripsi Anda
Apple Push Notification Pengiriman notifikasi Payload notifikasi kosong
RevenueCat Transaksi pembelian ID transaksi anonim

Vellum tidak menjual atau membagikan data apa pun dengan pihak ketiga untuk tujuan periklanan atau pemasaran.

4. Fitur Hadiah dan Berbagi Data

Saat Anda mengirim kapsul sebagai hadiah kepada seseorang:

  1. Sebuah CKShare dibuat di akun iCloud Anda (sistem berbagi bawaan Apple).
  2. Tautan (Tautan Universal) dikirim ke penerima.
  3. Ketika penerima membuka tautan, kapsul disalin ke akun iCloud mereka.
  4. Kapsul sekarang berada di akun penerima.

Sepanjang proses ini, Vellum tidak menyimpan data di servernya. Seluruh transfer terjadi melalui Apple iCloud.

Informasi penerima seperti nomor telepon dan nama disimpan dalam metadata kapsul dan tetap berada di akun iCloud Anda sampai kapsul mencapai penerima. Ketika mereka menerima, metadata ditransfer kepada mereka.

5. Retensi Data

Kapsul Vellum disimpan selama Anda menyimpannya atau sampai Anda menutup akun Anda. Tidak ada penghapusan otomatis. Kapsul Anda adalah milik Anda.

Statistik penggunaan anonim disimpan oleh Apple Analytics selama 7-14 hari.

6. Hak Data Anda

Sebagai pengguna Apple iCloud, Anda memiliki hak-hak berikut (melalui Apple):

  • Hak untuk mengakses: Anda dapat melihat kapsul Anda melalui iCloud Drive.
  • Hak untuk menghapus: Anda dapat menghapusnya kapan saja dari aplikasi atau dari Pengaturan iCloud.
  • Hak atas portabilitas: Apple memungkinkan Anda mengekspor data iCloud Anda (privacy.apple.com).
  • Hak untuk memperbaiki: Kapsul Anda adalah milik Anda, Anda dapat mengubahnya sesuka Anda.

Untuk permintaan data khusus tentang Vellum: vellumcapsuleapp@gmail.com

7. Privasi Anak-Anak

Vellum tidak ditujukan untuk anak-anak di bawah 13 tahun. Jika kami mengetahui bahwa seorang pengguna berusia di bawah 13 tahun, kami akan menghubungi Apple untuk menghapus akun tersebut.

8. Transfer Data Internasional

Apple menyimpan data iCloud di pusat data globalnya. Rinciannya ada di kebijakan privasi Apple.

9. Perubahan Kebijakan

Kami dapat memperbarui kebijakan ini dari waktu ke waktu. Kami akan mengirimkan notifikasi dalam aplikasi ketika ada perubahan signifikan.
