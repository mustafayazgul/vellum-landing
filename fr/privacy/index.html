Politique de confidentialité

Dernière mise à jour : 19 mai 2026

Merci d'utiliser Vellum. Cette politique de confidentialité explique comment vos données sont traitées lorsque vous utilisez l'application Vellum ("Vellum").

Résumé rapide

  • Vellum n'a pas de serveurs.
  • Toutes vos capsules sont stockées dans votre compte Apple iCloud, cryptées de bout en bout.
  • Nous n'avons jamais accès à vos enregistrements audio, enregistrements vidéo ou notes personnelles.
  • Lorsque vous envoyez un cadeau, la capsule transite directement via iCloud vers le destinataire. Il n'y a aucun intermédiaire entre nous.
  • Nous pouvons collecter des statistiques d'utilisation anonymes ; ces statistiques ne vous identifient pas personnellement.

1. Qui sommes-nous

Vellum est développé par Vellum. Pour nous contacter : vellumcapsuleapp@gmail.com

2. Données que nous collectons

2.1 Données que nous ne collectons PAS

Vellum ne collecte, ne voit ni ne stocke sur ses serveurs les données suivantes :

  • Vos enregistrements audio
  • Vos enregistrements vidéo
  • Le contenu de vos capsules
  • Vos notes personnelles
  • Les informations sur le destinataire (numéros de téléphone, noms)
  • Les métadonnées des capsules que vous avez envoyées ou reçues

Tout cela est stocké dans votre compte Apple iCloud. Vellum est juste une interface — nous n'avons pas nos propres serveurs pour accéder à vos données.

2.2 Données gérées par Apple

Les éléments suivants sont gérés via les services Apple iCloud :

  • Le stockage des données CloudKit
  • La distribution des notifications push (service Apple Push Notification)
  • La synchronisation et la sauvegarde iCloud

La confidentialité de ces données est régie par la politique de confidentialité d'Apple : https://www.apple.com/legal/privacy/

2.3 Données d'utilisation anonymes (Facultatif)

Pour améliorer Vellum, nous pouvons collecter les données anonymes suivantes :

  • La fréquence d'ouverture de l'application
  • Les fonctionnalités utilisées (par exemple, appui sur "créer une capsule")
  • Les rapports de crash et statistiques d'erreurs
  • La version de l'application, le modèle de l'appareil, la version d'iOS

Ces données ne vous identifient pas personnellement. Le contenu de vos capsules n'est jamais inclus dans ces statistiques.

Si vous ne souhaitez pas que ces données soient collectées, vous pouvez le désactiver dans les réglages d'iOS : - Réglages → Confidentialité et sécurité → Analyse et améliorations → Partager avec les développeurs (désactiver)

3. Tiers

Vellum utilise les services tiers suivants :

Service Objectif Données consultées
Apple iCloud / CloudKit Stockage de données Vos capsules cryptées
Apple Push Notification Distribution des notifications Contenus de notification vides
RevenueCat Transactions d'achat ID de transaction anonyme

Vellum ne vend ni ne partage aucune donnée avec des tiers à des fins publicitaires ou marketing.

4. Fonctionnalité de cadeau et partage de données

Lorsque vous envoyez une capsule en cadeau à quelqu'un :

  1. Un CKShare est créé dans votre compte iCloud (système de partage natif d'Apple).
  2. Un lien (Universal Link) est envoyé au destinataire.
  3. Lorsque le destinataire ouvre le lien, la capsule est copiée dans son compte iCloud.
  4. La capsule est maintenant dans le compte du destinataire.

Tout au long de ce processus, Vellum ne stocke aucune donnée sur ses serveurs. L'intégralité du transfert se fait via Apple iCloud.

Les informations sur le destinataire, telles que le numéro de téléphone et le nom, sont conservées dans les métadonnées de la capsule et restent dans votre compte iCloud jusqu'à ce que la capsule atteigne le destinataire. Lorsqu'il accepte, les métadonnées lui sont transférées.

5. Conservation des données

Les capsules Vellum sont conservées aussi longtemps que vous les conservez ou jusqu'à ce que vous fermiez votre compte. Il n'y a pas de suppression automatique. Vos capsules vous appartiennent.

Les statistiques d'utilisation anonymes sont conservées par Apple Analytics pendant 7 à 14 jours.

6. Vos droits sur vos données

En tant qu'utilisateur d'Apple iCloud, vous disposez des droits suivants (via Apple) :

  • Droit d'accès : vous pouvez consulter vos capsules via iCloud Drive.
  • Droit de suppression : vous pouvez les supprimer à tout moment depuis l'application ou les réglages iCloud.
  • Droit à la portabilité : Apple vous permet d'exporter vos données iCloud (privacy.apple.com).
  • Droit de rectification : vos capsules vous appartiennent, vous pouvez les modifier comme vous le souhaitez.

Pour les demandes de données concernant spécifiquement Vellum : vellumcapsuleapp@gmail.com

7. Confidentialité des enfants

Vellum ne s'adresse pas aux enfants de moins de 13 ans. Si nous apprenons qu'un utilisateur a moins de 13 ans, nous contacterons Apple pour faire supprimer le compte.

8. Transferts internationaux de données

Apple stocke les données iCloud dans ses centres de données mondiaux. Les détails figurent dans la politique de confidentialité d'Apple.

9. Modifications de la politique

We may update this policy from time to time. We will send an in-app notification when there is a significant change.
